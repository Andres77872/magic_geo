# Marine distance with no marine source

Fresh generation now distinguishes an absent marine source from distance zero. The former distance search replaced unreachable infinity by the largest finite result, defaulting to zero. It also substituted any water cell when no marine cell existed. A supported zero-ocean configuration therefore gained a false coastal classification, the full proximity-humidity term, and coastal contributions in groundwater and species diagnostics. Freshwater lakes could incorrectly seed the same marine effects.

The adopted `marine_source_aware_continentality_v1` declaration retains ocean, continental shelf and inland sea as marine sources. Distance remains a shortest path along mesh edges, with the existing edge lengths and minimum length; it is not a direct nearest geodesic measurement. Actual marine cells have numeric zero. If no marine source exists anywhere in the declared graph, distance is null and `marine_distance_status` is `no_marine_source`. The oceanic-humidity diagnostic and marine coastal contributions are zero. The distance term of continentality takes its limiting value one, while its other terms remain unchanged. Regional and global means use defined distances and remain null when none exists; explicit counts accompany them.

This is a finite diagnostic convention for known source absence. Rainfall, other humidity, freshwater, rivers, wetlands and soils keep their separate inputs and effects. If marine sources exist but some cells cannot reach one through the declared graph, the producer refuses before mutating the world. It does not substitute a finite maximum for an unresolved path.

The source order remains final native geography and mesh → continentality → natural groundwater and ecosystem/species consumers. An independent module replays graph distances, the diagnostic equations, summary counts and region membership. Marked downstream output is accepted only after that parent check. Historical unmarked numeric output retains its previous dispatch; stray nulls and new statuses do not silently enter that branch. [Physical source and consumer evidence](../runs/no-marine-source-physical-review/README.md)

CSV preserves the null and appends the source status without shifting established columns. Markdown explains the mean and its scope. Debug Parquet retains an all-null floating-point distance column and the layer remains selectable. The viewer labels its neutral map “No marine source,” omits the numeric ramp and explains the selected cell's undefined distance. The exported color guide carries the same meaning. A live regional-table review also corrected the generic historical-availability notice for the new declared counts. These display checks explain declared data; the independent physical validator establishes graph consistency.

Verification retained the original failures before changes: six of nine initial physical controls and all six initial debug-export controls failed. The final physical/CSV selection passes **109 tests**; the debug/map-export selection passes **84 tests and 200 subtests**; the direct JavaScript handler run passes **82 tests**. These selections overlap with earlier runs and must not be summed as independent coverage.

One fresh full API invocation used the existing Earthlike configuration with 128 cells, eight plates, zero erosion iterations and zero ocean inventory. Its raw native result was captured before enrichment. Full enrichment, independent marine replay, CLI validation, binary serialization round-trip and debug export passed on the first invocation. All 128 cells retain null marine distance and zero oceanic-humidity diagnostic; the one region retains a null distance mean. Mean generated precipitation remains about 530.851 mm/year. This retained value demonstrates separate model outputs and is not evidence of a physically closed water cycle. Live browser checks used that exact cache.
