# Natural geo generation and maturation: deep scientific audit

Audit date: 2026-07-11

Scope: natural planet generation and maturation only; settlement and civilization layers are excluded.

Reference configuration: `configs/earthlike_seed.yaml`, including the canonical 4,096-cell Earth-like member.

## Executive verdict

The current system is best described as **internally well-audited deterministic procedural geoscience with reference-scaled nominal maturation, conservative first-order crust transport, exact directed boundary-segment kinematic evidence, persistent shadow mass provenance, bounded dry-rock counter-accounting, partial Earth-reference fit, and honest temporal provenance**. It performs real state mutation in the native plate/crust, hydrology, erosion, sediment, and final glacial-coupling stages. Native exact spherical control volumes support forward overlap transport that conserves source crust volume, density-weighted volume, and crust-age volume moment before tectonic process rules are applied; retained contributor-set area classes make the overlap membership auditable while explicitly coalescing disconnected pieces. A separate per-snapshot ledger now preserves every cross-plate reciprocal control-volume segment with canonical left/right orientation and independently replayable direct unsmoothed Euler kinematics and opening/remapped crust witnesses. A new deterministic crosswalk groups all same-step segments by persistent unordered plate pair and accounts for every multiplicity-two-or-greater membership class as either a conservative pair-wide candidate or an explicit unknown. It uses only source-snapshot plate IDs, same-step pair consensus, and destination endpoint incidence; it does not resolve a local fragment-to-segment link, connected topology, physical polarity, allocation, material fate, slab geometry/selection/transfer, swept area, or state mutation. Boundary velocities remain nominal rather than calibrated, and the currently emitted oceanic-side classification remains only a heuristic candidate. The later ordered rule effects are reason-resolved and independently replayed. A separate non-authoritative shadow ledger persists sparse dry-rock mass packets and exposes every rule-implied mass increase or decrease as unresolved. A finite three-table counter-model replays those requests against a numerical exchange reserve and closes arithmetic, but it does not establish physical donors, recipients, fate, solid-volume or phase evolution, mantle/slab processes, sediment coupling, or a globally conserved physical crust cycle. Erosion and sediment now share an authoritative geometric interface in which bedrock-surface elevation and mobile-sediment thickness are canonical and surface elevation is derived, with all native mutation paths independently replayed. That interface resolves geometry only—not sediment dry mass, density, porosity, compaction, grain provenance, chemistry, or stratigraphic basement. A controlled fixed-domain problem shows approximately first-order improvement under timestep halving, but the current moving-domain diagnostic contains worsening fields and does not support convergence. It is not yet a physically time-calibrated Earth-system evolution model.

## What “simulated evolution” must mean

For this project, three different claims need to remain separate:

1. **Procedural generation**: deterministic rules derive a plausible final state from a seed and parameters.
2. **Reference-scaled nominal maturation**: intermediate native stages mutate shared state over explicit configured intervals, selected continuous reference-step operators scale consistently, and refinement reduces adjacent-level self-differences in controlled problems.
3. **Physical-time evolution**: prognostic state variables advance through dimensionally defined time, conserve the relevant reservoirs, converge with spatial/time refinement, reproduce accepted benchmarks, and retain skill on independent observations.

The project satisfies the first, partially satisfies the second, and does not yet satisfy the third. “Evolution” is currently defensible only as **coupled nominal maturation under documented reference-step scaling**.

A scientifically mature layer should eventually demonstrate all of the following:

- a documented equation or algorithm and explicit units;
- a clear split between prognostic state, diagnostic output, and boundary condition;
- conservation or a fully reported source/sink ledger where conservation applies;
- invariance under irrelevant permutations and rotations;
- numerical stability and spatial/time convergence;
- accepted analytical or community benchmark tests;
- calibration on declared data and validation on held-out seeds, resolutions, regions, or datasets;
- uncertainty/sensitivity reporting and explicit limits of applicability.

Producer-equation replay is valuable, but it proves that the implementation matches the selected equation—not that the selected equation is scientifically adequate.

## Actual execution pipeline

The native and Python pipeline currently behaves as follows:

```text
planet parameters
  -> spherical mesh and adjacency
  -> seeded rotating Voronoi plate domains
  -> crust/lithology/topography initialization
  -> initial sea + equilibrium climate + annual hydrology
  -> repeated configured maturation transitions at a nominal timestep
       rotate plate centers
       -> reassign plate domains and boundary classes
       -> forward spherical control-volume overlap crust transport
          with explicit destination gaps/overlaps
       -> record exact directed reciprocal control-volume boundary segments
          with same-step direct Euler kinematics and remapped pre-process crust state
       -> crosswalk every overlap-excess membership class to conservative
          pair-wide candidate evidence or an explicit unknown
       -> rule-based crust evolution
       -> evaluate tectonic, reference-scaled hillslope, and
          reference-scaled stream-power tendencies before terrain commit,
          using the prior stabilized surface/hydrology with updated crust
       -> compose provisional terrain
       -> route fluvial sediment on the prior flow graph using provisional
          terrain for accommodation
       -> finite-inventory update and terrain commit
       -> (sea-volume solve -> equilibrium climate
           -> annual land-water partition -> routed hydrology
           -> numerical depression correction) until stable
  -> derive cryosphere state -> one bulk glacial-sediment coupling stage
       -> finite-inventory/terrain commit and hydrologic stabilization
       -> recompute cryosphere state on the stabilized terrain/climate
  -> static native soils, biomes, resources, landforms, lakes, watersheds,
     coasts, sedimentary basins, and stratigraphy
  -> Python natural diagnostics and reconstructed trajectories
  -> explicit temporal-provenance registry
```

`generate_geo_world` now calls a separate native entry point that executes this natural sequence and skips settlement, route, political, cultural, historical, demographic, conflict, dynasty, and territorial generators. The serializer still emits stable empty/default schema placeholders; the Python boundary removes those before any natural enricher can consume them.

Only the configured erosion transitions advance nominal time. The initial state, stabilization subrecords, and terminal cryosphere/glacial operator are endpoint operations with zero nominal duration.

An integration test generates full and geo-only native worlds from the same seed, removes civilization fields from both, and requires exact dictionary equality. This proves that the new scope boundary changes execution cost and exposure without changing the natural result.

## Layer-by-layer status

### 0. Planet parameters and boundary conditions

**Actual model.** Radius, gravity, rotation, obliquity, eccentricity, luminosity, pressure, greenhouse factor, ocean water inventory, internal heat, and geological age are validated inputs and exported as a snapshot. Broad “realism” indices are heuristic diagnostics.

**Evidence.** Finite/range checks exist on both Python and native boundaries. Paired scenarios exercise hot/cold forcing, low/high obliquity, thin atmosphere, small/super-Earth radius and gravity, low/high ocean inventory, and stagnant/active tectonic controls.

**Verdict.** The boundary schema is engineering-valid. It is not a formation, atmospheric escape, volatile partition, interior cooling, or orbital evolution model. `geological_age_ga` bounds crust age but does not define the maturation clock.

**Next acceptance gate.** Introduce dimensionally physical boundary ledgers: stellar flux and orbital distance, atmospheric column mass/composition, surface gravity consistency, and total volatile/water reservoirs. ### Required path from rule accounting to physical crust provenance

The ten-reason state-moment ledger, shadow packet ledger, and finite dry-rock accounting history must not be relabeled as physical transfer ledgers. A cell still has one authoritative mean thickness, density, age, type, and lithology outside the accounting shadow. The shadow persists sparse origin composition; the finite counter-model gives every unresolved request numerical source/destination table entries and enforces a bounded exchange inventory, but every transfer explicitly has `physical_basis_resolved: false`. Several current rules change implied dry-rock mass without identifying a physical mechanism. In particular, ridge relaxation changes thickness/density independently, continental rifting removes thickness without a physical recipient, collision/accretion add thickness without physical donors, the “oceanic convergence subduction proxy” adds thickness rather than removing a slab, thickness bounds create/destroy volume, and density bounds change implied mass at fixed volume. Replaying those deltas against an exchange counter-reserve closes arithmetic; it does not cure the mechanisms.

The current counter-model instantiates cell-owned surface packets, one finite global `upper_mantle_exchange` pool shared by every cell, and plate-owned `subducted_slab` tables, but only as `finite_accounting_shadow`. Its `76 km * 3.08 g/cm3` capacity is an intentionally uncalibrated numerical envelope and not an estimate of upper-mantle mass. The mantle withdrawal policy is deterministic bookkeeping—instantaneous access to a spatially unresolved global pool, initial exchange reserve first, then largest packet with lowest-key tie-break—rather than mantle transport, melting, or lithosphere production. Origin-key packets remain distinct rather than homogenized. The slab tables are structurally present but empty. A physical successor must be authoritative for dry-rock mass and solid volume, derive surface thickness/density from that state, introduce calibrated phase and age tracers, and connect actual ridge creation, rifting, accretion, erosion/sediment, subduction, slab storage, melt, and return fluxes. The present volume-weighted age moment is not a conserved material quantity.

The overlap arrangement is the right geometric foundation and now retains source membership area. Each destination class records its area and sorted source cell/plate contributors, and its classes reconstruct every raw overlap edge. The storage is intentionally area-class rather than topology: disconnected atomic pieces with the same contributors coalesce, and only the largest atom supplies a representative. By itself it cannot identify connected bodies, overriding/subducting sides, or physical fate. The directed reciprocal segment ledger separately resolves the exact left/right contact and local unsmoothed relative Euler motion, including opening-remapped side witnesses. The new candidate-fate crosswalk now bridges those artifacts conservatively: it groups all same-step segments of one stable plate pair, requires unanimous pair-wide evidence, checks only whether the destination is any endpoint of that pair, and maps an eligible binary class's plate roles back to global contributor-CSR indices. It never uses the class representative and explicitly leaves local atom/fragment-to-segment linkage false. Multiplicity zero can fund juvenile crust only through a physically justified mantle-to-surface transfer in a divergent gap; the present legacy compensation is not that justification. Multiplicity one can transport identified packets. Multiplicity two or more still needs physical retention, stacking, accretion, or slab-transfer rules based on connected composition and independently resolved polarity evidence. Numerical envelope bounds must become physical flux limits or failed invariants, not mantle claims.

The diagnostically authoritative candidate-fate mapping is now implemented, but it is physically non-authoritative and deliberately stops before allocation. Every multiplicity-two-or-greater class contributes its full `(multiplicity - 1) * area` to exactly one diagnostic bucket: physical-polarity-backed candidate, unanimous oceanic-side heuristic candidate, or unresolved. Current generated worlds cannot enter the first bucket because the upstream physical polarity is explicitly unknown. Even a candidate row is only pair-wide evidence plus destination endpoint incidence; disconnected pieces coalesced into the same class are not localized, and the aggregate pair record is not standalone physical provenance without following its segment IDs back to their source/confidence fields. A later physical implementation may assign a physically polarity-backed, locally linked subducting contributor to a slab while resolving the existing multiplicity-two-or-more overlap transport. It must not independently add `segment_length * convergence_rate * dt` as a second surface-to-slab transfer: the rotated-control-volume overlap has already expressed the same relative motion as gap, single coverage, and excess multiplicity, so an additional swept-area withdrawal would double-consume the kinematics. Swept area can initially serve as an independent calibration, Courant/stability, and consistency diagnostic against overlap excess, not as another mass source. Unknown or disconnected mappings must remain unresolved.

Safe-sequence step (1) is complete as audit evidence: mass/provenance is shadow-advected through overlap edges, opening inventories link exactly to prior closing inventories, and ordered rule-implied mass changes are exposed while every physical-process resolution flag remains false. The shadow allocation normalizes each source over the sum of its raw overlap areas and puts the floating-point remainder on the final edge; `shadow_minus_raw_transport_residual_kg` remains a numerical geometry diagnostic. A second numerical step is also complete: contributor-set areas are retained and unresolved requests replay through a finite three-reservoir counter-model with global/per-origin/per-reservoir closure and fail-closed insufficient-exchange semantics. A third evidence step is complete: exact directed contact geometry and direct local kinematics are retained and independently reconstructed without trusting the smoothed cell forcing. A fourth diagnostic step is complete: the candidate-fate crosswalk independently replays all pair consensuses, eligible class rows, contributor-CSR roles, and overlap-excess area buckets while all allocation, physical, topology, slab, swept-area, and mutation flags remain false. These steps still do not resolve physical sources, connected material topology, fate, physical polarity, solid volume, phase, mantle, slab, or sediment coupling. The remaining sequence is to resolve polarity from observed/supplied or physical state, establish local connected-fragment-to-segment evidence, replace legacy compensation with physically resolved gap/overlap transfers and named accretion/recycling/arc-return processes, populate slab state only through polarity-backed overlap fate rather than a duplicate swept-area transfer, and couple basement erosion to the sediment system for whole-rock closure. `tectonic_process_material_provenance_resolved` can become true only when proxy/unresolved adjustments are roundoff-only, all physical reservoirs stay nonnegative, every transfer has a physical basis and endpoints, global and per-provenance mass close, and authoritative surface state derives from the ledger.

## Numerical and interface risks

### Conservative overlap implementation boundary

The current conservation claim is deliberately narrower than “physical crust conservation.” Native code forward-rotates every source polygon, uses a spherical cap index to select candidate target cells, clips triangle fans in each destination gnomonic chart, and rejects source-area closure errors above `max(1e-6 km2, 2e-10 relative)`. It directly checks crust volume, density-weighted volume, and crust-age volume moment from source to transported state; reconstructs each destination's integer coverage multiplicity; aggregates global area by multiplicity; records maximum raw arrangement line/atom counts; and requires global uncovered and overlap-excess area to balance. Atoms sharing identical sorted source contributors are then coalesced into one retained membership-area class. The canonical Python validator independently replays serialized sparse algebra, class-to-edge area reconstruction, histograms, inventories, and process deltas. A separate O(N²) implementation independently rediscovers pairs and recomputes every geometric intersection/coverage arrangement and contributor-set area on the 128/162 fixtures without requiring equal raw split counts, but is deliberately capped at 1,024 cells until it gains an independently implemented spatial index. The destination line arrangement aborts if a local coverage partition exceeds 16,384 atoms. In the geometry-stable 4,096-cell, seven-step native reference, `3,483,059` raw atoms coalesce to `109,777` classes (about `31.7x`) with a maximum of 14 classes per destination. The `178,764,102`-byte output and `371,176 KB` direct-native-process maximum RSS belong only to the historical pre-initial-age/expanded-round-trip checkpoint; current payload size/RSS has not been remeasured.

The shadow material layer deliberately uses a different normalization boundary from the authoritative state remap. Raw overlap areas remain untouched in `crust_overlap_ledger`, so their row-closure error and physical gap/excess interpretation remain observable. Shadow packets divide by each source's accumulated raw overlap area, traverse destinations in canonical order, and put the final subtraction remainder on the last edge. This preserves every opening packet for provenance auditing; `shadow_minus_raw_transport_residual_kg` records the resulting difference from raw transported density-weighted volume. Ordered positive adjustments are unresolved source packets, while negative adjustments preserve the removed origin keys. Independent replay uses sequential-double arithmetic where native ordering matters and operand/ULP-scaled bounds for cross-language mirrors.

The finite dry-rock accounting layer consumes those shadow requests without upgrading their scientific status. Packet tables use owner offsets and the canonical `(origin_domain_id, origin_kind_id, origin_plate_id)` key. Transactions are reason-major, with all surface sinks in ascending cell/key order before sources. Surface removal is proportional; mantle-to-surface compensation consumes the initial exchange-reserve packet before the largest remaining packet with lowest-key tie-break. Every cell accesses the same global pool instantaneously; origin keys are retained, but spatial mantle transport is absent. The exchange capacity is a numerical surface-state envelope, not mantle mass. Slab owner tables are emitted but empty, and transfer `physical_basis_resolved` values are uniformly false. Global/per-origin/per-reservoir closure therefore demonstrates deterministic finite accounting only.

The strongest current legal-motion stress cases use 180° per step with 32 plates. The 512-cell Fibonacci case produced 2,279 retained CSR edges, at most 17 contributors per destination, maximum multiplicity 5, at most 92 arrangement lines and 1,844 raw atoms, `5.97e-15` maximum relative source closure error, and `3.01e-6 km2` maximum destination partition error. The 642-cell geodesic case produced 2,692 edges, at most 24 contributors, maximum multiplicity 7, at most 132 lines and 3,835 raw atoms, `1.176e-14` source error, and `7.26e-6 km2` destination error. Both remain below the 16,384-atom cap. These tests materially exercise large rotations and high local mixing, but they are not an exhaustive combinatorial or worst-case proof of the bound.

This transport remains CPU-authoritative even when the selected world backend is OpenCL or CUDA. A separately named shadow consumes the exact CPU CSR and source continuous state, computes the three transported moments and derived thickness/density/age with one ordered FP64 work item per destination, validates the result against finite operation/operand-count bounds, records dedicated counters/errors, and discards it. Complete production overlap dispatch remains zero. Geometry, pair discovery, clipping, gaps/excess, membership classes, categorical selection, production remap, and scientific state remain CPU-authoritative and complete parity remains false. Separately, the post-transport rules expose ten quantitative ordered state-moment records for aging, ridge rejuvenation/relaxation, convergence, collision, rifting, crossing accretion, and bounds. Retained area classes identify contributing sources but deliberately resolve neither connected topology nor fate. The directed segment ledger resolves exact contact identity and direct local Euler kinematics, but its km/Ma scale is nominal and its oceanic-side result is only a candidate. The new crosswalk consumes that ledger only to publish and validate pair-wide diagnostic rows; no physical process rule, slab transfer, or state mutation consumes it. Shadow packets preserve audit-origin keys, and the finite counter-model supplies numerical reservoir endpoints, but metadata explicitly keeps physical source/sink attribution, transfer basis, material provenance, mantle/slab resolution, sediment coupling, subduction polarity, and material fate false. The records identify which rule changed serialized mass and how accounting packets balance, not which physical mechanism supplied or received matter.

That smallest additive accelerator gate is now implemented with separate aggregate/OpenCL/CUDA counters, fail-closed malformed-input and numerical-mismatch paths, identity/gap/overlap/empty-row and 24-contributor unit cases, and conditional two-transition device tests. Default Release, strict Release, and strict Debug all pass the complete 12-test native suite. This host reports no usable OpenCL platform, no CUDA compiler, and no CUDA device, so OpenCL runtime compilation/execution and CUDA translation-unit/device execution remain external-lane requirements. The next accelerator gate is device-enabled validation and performance evidence for this shadow, followed—only if justified—by separately reconciled geometry/classes/categories. No shadow result should become production state merely because the continuous reduction passes.

### Temporal refinement evidence and limits

The dedicated refinement harness compares endpoint states over the same 10 Ma **nominal** horizon at timesteps of 5, 2.5, and 1.25 Ma on the same 128-cell mesh and seed. For the controlled test, plate centers are held fixed to remove discontinuous domain reassignment while angular speeds and tectonic boundary forcing remain nonzero. With `E(h)` denoting the area-weighted L2 self-difference between adjacent endpoint refinements, the observed order is `p = log2(E(5,2.5) / E(2.5,1.25))`:

| Endpoint field | E(5, 2.5) | E(2.5, 1.25) | Observed order p |
|---|---:|---:|---:|
| Elevation (m) | 5.282105 | 2.574906 | 1.0366 |
| Sediment thickness (m) | 4.944410 | 2.474118 | 0.9989 |
| Sediment production (m) | 3.983455 | 1.934673 | 1.0419 |
| Crust thickness (km) | 0.002642 | 0.001303 | 1.0199 |

This is credible first-order behavior for those selected smooth fields in that restricted problem, not a whole-model convergence certificate. Per-cell cumulative terminal export is a hybrid localized diagnostic: a drainage-capture switch between outlets 7 and 12 makes its three-level L2 sequence worsen from `0.22404` to `0.49209 m` even though the adjacent global export-volume difference decreases from `12,012.51` to `10,310.31 km3` and all sediment ledgers close. Thresholded soil/productivity classifications likewise change discontinuously and are checked for exact native-source preservation, valid ranges, and nominal-history linkage rather than pointwise order. The v2 moving-domain diagnostic runs the same 10 Ma nominal horizon at 5, 2.5, 1.25, and 0.625 Ma on Fibonacci 128 and geodesic 162. It reports three adjacent-level L1/L2 differences, categorical area mismatch, endpoint extensive differences, and source-to-transported closure rather than reducing the result to a pass/fail claim. One history-wide mask is chosen without reading any error magnitude: a cell is included only if its serialized plate/material and water/routing discrete branch signatures remain identical through every snapshot in all four worlds. For every continuous field and adjacent pair, exact rational sums of the already-rounded binary64 `area * difference²` terms close `full SSE = invariant SSE + recorded-change SSE`; this is attribution, not filtering, and full-domain error remains primary. Continuous threshold and clamp branch stability is explicitly unresolved.

The invariant cohort contains 61/128 Fibonacci cells (47.6826% of area) and 126/162 geodesic cells (77.9587%). On Fibonacci, the 2.5→1.25 Ma full-domain ratios worsen for sediment thickness (`1.20785`), production (`2.30414`), export (`1.37242`), temperature (`1.42866`), and runoff (`3.50494`), while every field falls below one at 1.25→0.625 Ma. On geodesic, every medium→fine field decreases, but the finest sediment-export and temperature ratios worsen to `1.56599` and `1.08340`; their invariant-cohort ratios are `0.60371` and `0.46368`, while recorded-discrete-change cells carry 85.3620% and 93.0684% of their full SSE. Categorical crust-type mismatch falls to zero at the finest pair on both meshes, but earlier nonzero branch changes remain part of the history-wide exclusion. Transport closure remains excellent (`1.77e-15` Fibonacci and `1.60e-15` geodesic maximum relative error), demonstrating that conservation is compatible with an endpoint for which convergence has not been demonstrated. The diagnostic is deliberately labeled `diagnostic_only_not_convergence_certificate`, and `time_step_convergence_demonstrated` remains false. It still needs spatial refinement, more seeds, a finer temporal reference, global-rigid-rotation and differential-boundary cases, and topology-aware acceptance rules. Discrete modal projection, arc numeric guards, `.10/.18/.24/.26/.28` process thresholds, the per-step tectonic-elevation clamp, repeated fixed-grid remapping, and drainage/routing thresholds remain structural risks. Equal cumulative plate rotation proves only kinematic angle integration, not convergence of transported and coupled state.

This separation follows standard numerical-analysis practice: algorithmic drainage iterations are not automatically physical timesteps; diffusion and stream-power solvers require explicit stability/convergence analysis; and operator ordering can set the splitting error. Relevant references include [Steer, 2021](https://doi.org/10.5194/esurf-9-1239-2021), [Perron, 2011](https://doi.org/10.1029/2010JF001801), [Braun and Willett, 2013](https://doi.org/10.1016/j.geomorph.2012.10.008), and [Strang, 1968](https://doi.org/10.1137/0705041). Recent coupled-landscape studies further show that timestep, grid, and routing choices can alter response and that plausible-looking coupled solutions can still be numerically wrong: [Gasparini et al., 2024](https://doi.org/10.5194/esurf-12-1227-2024) and [Coatleven and Chauveau, 2024](https://doi.org/10.5194/esurf-12-995-2024).

Before the control-volume/v3 transport change, the v12 clock-only update was backward-compatible at the scientific-output level: all 646 common metric values across 19 baseline members were unchanged, as was the external-calibration object. The matrix pair represents the same 10 nominal Ma as 5 Ma × 2 and 2.5 Ma × 4 and integrates the same cumulative plate rotation. Exact control-volume areas, conservative overlap, the corrected age-depth target, replayable initial ages, and source-matched external semantics changed downstream scientific values and the empirical bundle, so the old hashes remain historical. The freshly regenerated v3 matrix confirms complete 22/22 coverage and 17/22 passes. Natural Earth coastline, all three ETOPO relief metrics, and HydroBASINS non-Antarctic endorheic watershed area fail; 19/21 internal and overall scenario policies, all 294 layer contracts, and all 26 paired relations pass.

### Resolution dependence

Coastline fraction, endorheic area, basin hierarchy, and Hack’s exponent depend strongly on mesh resolution and cell-center topology. A single 4,096-cell comparison cannot establish scale-independent realism. On an Earth-radius sphere, that mesh has an equivalent cell width `sqrt(4 * pi * R^2 / 4096) ≈ 353 km`, already larger than the observed `180–275 km` trench-to-arc interquartile range reported by [Syracuse and Abers (2006)](https://doi.org/10.1029/2005GC001045). Current one- or two-hop arc-location checks are therefore qualitative topology checks, not a resolved validation of trench–arc distance. Every scientific metric needs either a scale-matched target or demonstrated convergence to a stable value.

### Precision is currently scientific state

`output.float_precision` still rounds general/display native JSON before Python enrichers run, although the replay-critical crust, equilibrium, boundary, transport, elevation, and water-depth roots now override it with binary64 round-trip serialization and the sediment interface retains its separate 10/8-decimal contract. The remaining rounded fields can therefore change downstream diagnostic classifications and scores; the setting is not merely presentation formatting. The long-term design should pass typed native arrays/state directly to enrichers and round only final serialization.

### Cell omission

Python natural enrichers require per-cell state. `generate_geo_world` now rejects `output.include_cells=false` instead of silently producing absent/empty scientific layers.

### Build and package integrity

Default Release remains staged beside the Python package for the documented editable workflow. Non-Release configurations now write to build-local directories, and Debug CTest’s RUNPATH was verified to point to its own library; the Release library checksum stayed unchanged during the Debug build.

Setuptools still does not invoke CMake, so the documented Release build remains an explicit wheel prerequisite. The packaging gate now selects only the current platform's staged filename, loads it, checks required ABI symbols, emits a non-pure `py3-none-<platform>` wheel, and includes the complete web UI. A rebuilt source archive includes `CMakeLists.txt` and all C++ sources while excluding staged host binaries. This closes the former missing-core/universal-wheel and non-rebuildable-sdist failures, but it is not a manylinux audit: the local Linux wheel's glibc, libstdc++, and OpenMP runtime requirements still follow the build host. A CMake-aware backend such as `scikit-build-core` remains the cleaner future path for automatic builds and portable wheel production; Python tests bound to `$<TARGET_FILE:magic_geo_native>` remain desirable.

There is also no checked CI workflow, sanitizer lane, strict-warning lane, compiler/build-type matrix, clean wheel smoke test, or Python registration under CTest. Those omissions weaken reproducibility even though the recorded native and focused suites pass; the full Python discovery gate is reported separately in the verification table.
